# 求是西行 · 1937

根据《求是西行-1937_开发精简版_图片标注.md》制作的完整网页试玩版。上方场景图，下方文字和选项；全部图片为原创几何占位图。

## 文件与启动

- `index.html`：完整游戏，包含页面样式、剧情和程序。
- `assets/images/`：19 张可替换的场景与道具图片。
- `assets/素材说明.md`：图片编号、用途与替换说明。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件，可保留。

无需安装 Node.js、Vite、Ren’Py 或其他运行库；没有外部字体、脚本或联网接口依赖。设计支持完整解压后用现代浏览器打开 `index.html`。本次浏览器实测使用本地 HTTP 预览，并验证了 `/qiushi-game/` 子目录地址；测试浏览器不允许访问 `file:` 地址，因此双击文件方式未在该工具内验证。

已安装 Python 的电脑，也可在文件夹中运行：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。Windows 使用 `py -m http.server 8000`。

## 上传到独立 GitHub 仓库

1. 在 GitHub 新建公开仓库，例如 `qiushi-game`，和个人网站仓库分开。
2. 解压交付 ZIP。进入包含 `index.html` 的文件夹。
3. 在新仓库点击 **Add file → Upload files**，上传 `index.html`、整个 `assets` 文件夹和本说明；如果能看到 `.nojekyll`，一起上传即可。**不要上传 ZIP 本身，也不要把所有内容再套进一个外层文件夹。**
4. 提交后，仓库首页应直接看到 `index.html` 和 `assets/`。
5. 打开 **Settings → Pages**。
6. Source 选择 **Deploy from a branch**；Branch 选择 **main**；Folder 选择 **/(root)**，点击 **Save**。
7. 等待发布完成，点击 **Visit site**。通常网址为 `https://你的用户名.github.io/qiushi-game/`。若仓库或账号使用自定义域名，以 Pages 显示的网址为准。

后续修改文件并提交，Pages 会重新发布。所有素材使用相对路径，适合项目仓库的子目录网址。本次未创建 GitHub 仓库、上传文件或实际部署；交付的是可直接上传的静态文件包。

官方设置说明：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 怎么玩

- 输入姓名后点击“开始西行”。姓名留空默认“江潮生”。
- 点击“继续”推进对白；普通对白也支持空格或右方向键。
- 展厅先看箱子、合影、日记，再展开路线图。
- 遇到选择点，点击你的选择。问答全部选完后统一提交。
- 拼校训时，按顺序点击两个字；提交前可以再次点击撤选。
- 右上角“手账”查看本局记录与三项数值；“章节”查看路线目录。
- 结尾回忆可自动播放或跳过。最后两问可以填写，也可以留白。
- **第一版不保存进度：刷新或关闭页面会重开。**终章输入只留在当前页面，不上传。
- “重来”经确认后清空本局分数、手账和选择。音乐和配音本版留空，全部交互可静音游玩。

## 当前内容

从2026年校史馆，经杭州、天目山、建德、吉安、泰和、宜山、遵义／湄潭，到1946年返杭并回到2026年。

共142个剧情节点、11个互动、5次核心抉择、5种结局。包含护书支线、三道夜读题、测量二选一、点击字块拼校训、灯下校样、领取与点亮费巩灯、挂校牌、手账、走马灯和历史时间轴。

五种结局为“求是”“藏书楼”“澄江”“湄潭灯”“隐没·无名”。按新版规则先判断失误，再判断护书成功与均衡，最后比较人心／薪火／求真。失误数不向玩家显示。

## 替换图片和修改剧情

图片按 `assets/images/IMG-01.webp` 等编号调用。用同名 WebP 覆盖即可，背景建议1600×900。无需修改程序路径，也不要写入电脑上的绝对路径。历史合影IMG-25未使用史料照片，当前以宿舍示意背景和字幕呈现；人物立绘本版省略。

`index.html` 内有三个可搜索的区块：

- `id="story-data"`：剧情、选项、图片编号、分数变化与结局文案。
- `id="game-core"`：初始状态与结局规则。
- `id="game-engine"`：界面和按钮行为。

改剧情时保留节点的 `id` 和 `next` 连接，不要删除JSON里的引号或逗号。更新前先复制一份文件备份。

## 文本与素材说明

剧情来自提供的新版剧本。程序未导入附三Diff或制作备注。为解决原文内部衔接，护书段明确注明1939年插叙，留校选项明确随校迁往泰和，里程统一为原稿多处采用的“2600多公里”；这些整理不等于对全部史实的独立考证。

占位图不是历史照片或建筑复原；未使用北大《破晓以后》的图片、音频或视频。图片为本项目程序绘制，详细用途见素材说明。历史人物对白含文学创作，正式公开展示前可继续核对引用与史料。
